# Generative AI – Image Caption Generation for Scene Analysis

A beginner-friendly image-captioning demo built with Python, Streamlit, and the pretrained BLIP model from Hugging Face.

## What it does

1. Lets a user upload a JPG, JPEG, PNG, or WEBP image.
2. Passes the image to BLIP.
3. Displays the caption generated by the model.

## Requirements

- Python 3.10–3.12 recommended
- Internet access for the first model download
- VS Code (recommended, but optional)

The model download and inference can take time, especially on a laptop with limited RAM.

## Run on macOS

Open Terminal in this folder and run:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

If the browser does not open automatically, visit http://localhost:8501.

## Run on Windows

```powershell
py -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Model

The app uses `Salesforce/blip-image-captioning-base`, a pretrained image-captioning model. It downloads model files from Hugging Face the first time it runs and caches them for later use.

## Important notes

- This is a working starter/demo, not a validated production system.
- Generated captions may be inaccurate or incomplete.
- Do not claim “98% accuracy” unless your team has a defined dataset, evaluation metric, and results to support that figure.
- This app uses the pretrained model; it does not train or fine-tune BLIP.
